# kiber-immunity

Учебный проект по проектированию сложной технической системы с кибериммунным подходом.

**Тема:** Сервис онлайн-маркетплейса как система для анализа с точки зрения кибербезопасности.

## Этапы со стороны Заказчика

1. **КБП** — ценности, негативные события, оценка ущерба.
2. **Контекст** — диаграмма взаимодействия с внешними системами.
3. **Базовые сценарии** — диаграммы последовательности.

## Этапы со стороны Исполнителя

1. **HLA** — архитектура без учёта кибериммунности.
2. **Базовые сценарии + HLA** — реализация сценариев на компонентах.
3. **ЦПБ** — цели и предположения безопасности.
4. **Негативные сценарии** — компрометация компонентов и её влияние на ЦБ.
5. **Политика архитектуры** — распределение по DFD-доменам с оценкой сложности и обоснованием.

## Результат
Архитектурное решение, доказывающее достижение всех целей безопасности при заданных предположениях.
