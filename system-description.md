# Концепция продукта

**Наша тема:** Сервис онлайн-маркетплейса как система для анализа с точки зрения кибербезопасности

**Сервис онлайн-маркетплейса** — это информационная система, предназначенная для организации взаимодействия между покупателями и продавцами: размещения каталога товаров, оформления и оплаты заказов, управления статусами заказов, взаимодействия со службами доставки, ведения истории покупок и отзывов, а также администрирования платформы.

**Основные внешние сущности:**
* Покупатель — просматривает товары, оформляет заказы, оплачивает покупки, оставляет отзывы;

* Продавец — размещает товары, обрабатывает заказы;

* Платёжный сервис — обеспечивает проведение платежей;

* Служба доставки — получает данные заказа, доставляет их и передаёт статусы доставки;

* Сервис уведомлений — отправляет e-mail уведомления;

* Администратор платформы — управляет всей платформой.

* Служба поддержки — консультирует пользователей и продавцов, решает споры, фиксирует недостатки работы приложения.

Система функционирует в условиях недоверенной внешней среды: запросы пользователей могут быть вредоносными, внешние сервисы могут быть недоступны или скомпрометированы, а данные из внешних источников не считаются достоверными.
