# КБП

| Ценность | Негативное событие | Ущерб | Комментарии (способы противодействия?) |
|---|---|---|---|
| Персональные данные покупателей и продавцов | Утечка данных, неправомерный доступ, потеря аккаунта | Высокий: потеря доверия пользователей, потеря критически важных для пользователя данных (данные банковкой карты, контакты)| шифрование, токенизация, разграничение доступа |
| Данные для проведения платежей | Кража личных средств, вывод (перевод) денег | Критический: финансовые потери | Не хранить полные данные карт, токенизация, шифровка, антифрод |
| Данные заказов: состав, сумма, адрес, статус | Подмена или искажение достоверных данных | Высокий: неверная доставка, споры, возвраты | Валидация, подпись сообщений |
| Каталог товаров, цены | Несанкционированное изменение информации о товарах| Высокий: финансовые потери, недоверие | Права продавца, модерация, логирование изменений |
| Учётные записи продавцов | Захват аккаунта | Высокий: мошеннические товары, вывод средств | Двухфакторная аутентификация, проверка входов, уведомления |
| Учётные записи администраторов | Зловредное использование прав администратора | Критический: полный контроль над платформой | Отдельный контур, логгирование действий |
| Средства и расчёты продавцов | Несанкционированная выплата | Критический: прямые финансовые потери | Лимиты на вывод средств, двойное подтверждение, сверка, антифрод |
| Отзывы и рейтинги | Накрутка или фальсификация | Средний: искажение выбора, репутационные потери | Привязка отзывов к заказам, антифрод, модерация |
| Логи и события безопасности | Уничтожение или подмена | Высокий: невозможно расследовать инцидент | Отдельное хранилище, резервные копии, неизменяемое хранение, ограниченный доступ |
