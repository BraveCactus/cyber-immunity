# КБП

| Ценность | Негативное событие | Ущерб | Комментарии |
|---|---|---|---|
| Персональные данные покупателей и продавцов | Утчка данных, неправомерный доступ, потеря аккаунта | Потеря доверия пользователей, потеря критически важных для пользователя данных (данные банковской карты, контакты)| шифрование, токенизация, разграничение доступа |
| Данные для проведения платежей | Кража личных средств, вывод (перевод) денег | Финансовые потери | Не хранить полные данные карт, токенизация, шифровка |
| Данные заказов: состав, сумма, адрес, статус | Подмена или искажение достоверных данных | Неверная доставка, споры, возвраты | Валидация, подпись сообщений |
| Каталог товаров, цены | Несанкционированное изменение информации о товарах| Финансовые потери, недоверие | Права продавца, модерация, логирование изменений |
| Учётные записи продавцов | Захват аккаунта | Мошеннические товары, вывод средств | Двухфакторная аутентификация, проверка входов, уведомления |
| Учётные записи администраторов | Зловредное использование прав администратора | Полный контроль над платформой | Отдельный контур, логирование действий |
| Средства и расчёты продавцов | Несанкционированная выплата | Прямые финансовые потери | Лимиты на вывод средств, двойное подтверждение, сверка|
| Отзывы и рейтинги | Накрутка отзывов и оцнок или фальсификация | Искажение выбора, репутационные потери | Привязка отзывов к заказам, модерация |
| Логи и события безопасности | Уничтожение или подмена | Невозможно расследовать инцидент | Отдельное хранилище, резервные копии, неизменяемое хранение, ограниченный доступ |
